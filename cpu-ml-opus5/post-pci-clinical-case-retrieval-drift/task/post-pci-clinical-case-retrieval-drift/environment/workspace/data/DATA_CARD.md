# Case corpus data card

This task uses the supplied corpus of 1,500 distinct real PMC case-report records: 500 cardiac, 500 vascular, and 500 systemic. Each JSONL record contains a PMCID, title, journal, final diagnosis, case summary, and derived domain-hit counters. The landing snapshot also contains a second copy of one delivery file, exactly as received; release authority must be established from the incident evidence rather than inferred from the directory listing.

The index case is supplied as a pre-outcome PDF. No final CT result or final diagnosis is available to the retriever. All profile values come directly from the supplied files; no records are procedurally generated.
