Clinical Evidence Retrieval Service Contract

R10 incident copy | Effective 12 August 2026

This service produces a request-sized evidence panel for a pre-outcome post-PCI review. The public incident request asks for twelve cases. This copy defines the interface and operational acceptance boundary; it intentionally does not duplicate the release ranking, identity-join, or request-phase implementation.

Inputs

  • The release inventory is described by source_manifest.json.
  • The clinical request is described by query_facets.json and the pre-outcome PDF.
  • The landing snapshot may contain files or display identifiers that are not release authority.

Output interface

Return JSON with corpus_count, domain_counts, results, pmcids, and method. Each result contains exactly pmcid, source, and a numeric score. Serving requests honor a positive top_k up to the available release inventory.

R10 release behavior

The release is balanced across the three active cause families and is request-sized. Manifest entry order, JSON facet insertion order, and a global post-allocation score sort are not allocator authority. The request phase, canonical identity join, and accepted lexical/fusion behavior are released only as gated operational receipts after recovery; this incident copy is intentionally insufficient to reconstruct the hidden terminal offline.
